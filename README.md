# HSdeck Whizbangs Workshop 카드 API

`cards.json`과 `render.json`은 기존 HS Plus 카드 정보를 기반으로 하며, `art/`는 설치된 클라이언트의 원화입니다. `golden/`은 해당 카드의 원본 황금 원화 재질·애니메이션·텍스처입니다. 날짜별 과거 원화나 황금 효과를 보장하지 않습니다.


## API 편집 지침 (2026-11-14)

- 공개용 카드 데이터는 `cards.json` 목록, `data/<CARD_ID>.json` 한국 날짜별 카드 능력·효과, `art/` 일반 카드 원화, `golden/` 황금 카드·애니메이션, `frame/` 프레임·텍스처·셰이더입니다. 누락된 원본을 임의로 꾸며 만들지 않습니다.
- `render.json`, `history.json`, `*-date.json`은 더 이상 게시하지 않는 중복 집계입니다. 빌더가 생성하는 경우에도 임시 검증용으로만 취급하고 Git에 다시 올리지 않습니다. 신규 schema/호환 래퍼를 만들지 않습니다.
- 카드별 원본이 날짜 키 형식이 아니라면 근거·필드·첫 사용일을 보존한 무손실 변환을 먼저 합니다. 최초 날짜는 한국 실제 대전 가능일(베타 북미 시간 환산, 모험 지구 실제 개방, 이벤트 실개시일, 토큰 부모 생성 가능일)입니다.
- 오기입된 앞선 날짜 키는 삭제/통합하고 후속 날짜에는 바뀐 필드만 적습니다. 표시 개행은 `<br></br>`, 원시 자료 개행은 보존합니다. 황금·프레임 바이너리와 파일 경로는 임의 수정하지 않습니다.
- `release-policy.json`, `tools/`, `.github/`처럼 빌드/검증에서 참조하는 파일은 의존성을 확인한 후 정리합니다.
